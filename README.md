# Para Betsabé 🌻

Página web estática preparada para publicarse con GitHub Pages.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube **todo el contenido de esta carpeta a la raíz del repositorio**, incluyendo la carpeta `fotos`.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, luego guarda.
6. Espera unos minutos a que GitHub publique la página.

El archivo principal es `index.html` y las rutas son relativas, por lo que funciona tanto en un dominio `github.io` como en un proyecto de GitHub Pages.

> Nota: la canción incrustada de YouTube y las fuentes de Google necesitan conexión a Internet. Algunos navegadores bloquean la reproducción automática hasta que el visitante interactúa con la página.
